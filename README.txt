BIRTHDAY ACADEMIC WEBSITE
==========================

FILES
-----
index.html              Home page
abstract.html           Birthday abstract
literature-review.html  10 interactive achievement cards
future-research.html    Tap -> tap again -> reveal interaction
authors-note.html       Long personal letter
style.css               Entire website design
script.js               Interactions and mobile navigation

HOW TO USE
----------
1. Keep all files in the same folder.
2. Open index.html in a browser.
3. Edit the text directly inside the HTML files.
4. Save and refresh the browser.

IMPORTANT EDITING AREAS
-----------------------
index.html
  - Edit the introduction under "EDIT THIS INTRODUCTION".

abstract.html
  - Edit the birthday message inside "EDIT YOUR BIRTHDAY MESSAGE HERE".

literature-review.html
  - There are 10 achievement cards.
  - Edit each title and hidden text.
  - Do not remove data-reveal-card or data-reveal-card related classes.
  - Clicking a card reveals the content on the SAME PAGE.

future-research.html
  - Edit message-one if desired.
  - Edit message-two if desired.
  - Edit the hidden message inside message-three.

authors-note.html
  - Replace the sample paragraphs with your own letter.

DESIGN
------
The website uses:
- Playfair Display for the elegant serif typography.
- DM Sans for navigation and small labels.
- Responsive layouts for desktop/tablet/mobile.
- No backend.
- No database.
- No framework required.

If you want to use the site completely offline, download the Google fonts
and replace the font imports in style.css with local font files.
